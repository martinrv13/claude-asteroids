# Claude Asteroids

A classic Asteroids game built with vanilla JavaScript and HTML5 Canvas.

## How to play

Open `index.html` in your browser, or run a local server:

```bash
npx serve .
```

Then visit `http://localhost:3000`.

## Controls

- **Arrow Up** — Thrust
- **Arrow Left / Right** — Rotate
- **Space** — Shoot

## Features

- Level progression
- Lives system
- Particle explosions
- Asteroid splitting
